# Agents

This is a collection of simple CLI programs for experimenting with 3D graphics. The experiments are to explore visualizing geology data (block model and drill hole data). The CLI programs are written in Odin.

## view_bm
Visualize a geology block model. Colour palette is fixed. The TAB button cycles through each of block grades.

## view_dy
Visualize a geology drill hole file. The drill hole data is desurveyed.
