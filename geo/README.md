# Agents

This is a collection of experiments related to processing or analysing geology data.

## PPMT
A series of experiments in developing and testing an R implementation of the Projection Pursuit Multivariate Transform (PPMT). The PPMT is a useful data transformation technique that allows constructing a multivariate Gaussian data set where each variable is independent. Useful for ensuring independent estimates of grade retain the global drill hole statistical relationships--necessary for predictive geometallurgy.
