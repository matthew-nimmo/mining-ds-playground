## What is Mining DS?

Mining DS is a mining data science and analytics knowledge platform focused on:

- Geology
- Geometallurgy
- Resource Modelling
- Mine Planning
- Mineral Processing
- Mining Analytics
- Data Engineering
- Data Science for Mining
