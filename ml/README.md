# Agents

This is a collection of experiments in Machine Learning.

## dags
Quarto notebooks with R code for constructing and working with Directed Acyclic Graphs (DAGs).

## knn
A set of nearest neighbour algorithm implementations written in Go and Odin.

## scoring
Quarto notebook with R code for applying scoring functions for twin drill hole comparisons.

## traps
Quarto notebooks with R code for the statistical data traps. Traps include the Berkson's Paradox, the Simpson's Paradox, and Survivorship Bias.
